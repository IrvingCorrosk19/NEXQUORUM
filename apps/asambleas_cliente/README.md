# Asambleas — cliente Android

Aplicación del participante. Usa el servidor publicado de Asambleas. No administra PH, convocatorias ni la mesa.

## Instalación

1. En el teléfono, permite instalar aplicaciones de origen desconocido.
2. Copia `build/app/outputs/flutter-apk/app-release.apk`.
3. Ábrelo y confirma la instalación.
4. Entra con el correo del participante y su contraseña, o con un código enviado a ese correo.

La APK de desarrollo está firmada con la clave de depuración de esta máquina. No sustituye una firma de tienda.
