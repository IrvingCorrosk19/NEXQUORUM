# Live Voting Workspace

In-meeting voting controls live in `/assembly.html` (sidebar **Votación**).

Operators see:

- **+ Votación rápida** — create without leaving LiveKit
- **Usar preparada** — present existing draft/ready motion
- **Editar / Vista previa** — before open (or after withdraw)
- **Retirar apertura** — open + 0 votes
- **Anular…** — open with ballots (reason required) → optional V2
- **Nueva versión / Historial**

Video/audio stay mounted; only governance panel updates via SignalR.
