# Voting Operations

## Where to operate

1. Login → Dashboard → open assembly room: `/assembly.html?assemblyId={id}`
2. Ensure check-in/accreditation completed and assembly `InProgress`
3. Present motion (operator) if status is Draft
4. Voting panel: select result policy → **Abrir votación**
5. Owners vote in the same room URL (sticky mobile panel)
6. President monitors participation → **Cerrar votación**
7. Result appears in room; Decision/Acta via `/minutes.html` and `/evidence.html`
