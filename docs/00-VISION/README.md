# Vision — ASAMBLEAS

ASAMBLEAS is a PH Governance Operating System for Propiedad Horizontal assemblies:

Convocatoria → acreditación → poderes → asistencia → quórum → agenda → deliberación → mociones → votación → decisiones → actas → evidencias → ejecución → analytics → IA.

**EO-001** delivers only the enterprise foundation and a vertical virtual-assembly POC for 8 participants — not the full product.
