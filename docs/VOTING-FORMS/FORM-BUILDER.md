# Form Builder

Survey/form designer lives in Voting & Forms Studio (Formularios tab).

Supports:

- Multiple questions (SingleChoice, MultipleChoice, Scale, OpenText)
- Required flags, options JSON, preview (desktop/tablet/mobile)
- Publish validation server-side
- Responses unique per `(SurveyFormId, UserId)` + optional client request idempotency
- Results analytics (distribution / open text list)
- **No** automatic Decision / Voting Rule Engine
