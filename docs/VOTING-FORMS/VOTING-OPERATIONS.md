# Voting Operations

1. Open Studio from Panel or Sala → **Studio**
2. Create agenda point (auto-created if empty) → Nueva votación
3. Configure question, options, coefficient, threshold, visibility → Guardar → Publicar
4. In Sala: Presentar moción → Abrir votación
5. Owners vote (mobile drawer) → President closes → Decision + minutes + expediente

Survey path: Studio → Formulario → Publish → Submit responses → Results (no Decision).
