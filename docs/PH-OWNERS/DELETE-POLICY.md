# Delete policy

**Golden rule:** history ⇒ deactivate/archive; no history ⇒ safe hard delete if evaluation allows.

## PH

Blocked when assemblies / votes / recordings / quorum snapshots exist.

## Owner

Blocked when UserId appears in participants, attendance, votes, powers, or representations for assemblies of that PH.

Multi-PH: delete removes ownerships only in the requested PH; Owner entity removed only if no remaining ownerships elsewhere.
