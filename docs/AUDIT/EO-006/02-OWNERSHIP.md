# EO-006 — Ownership

`Ownership` is queried by `AssemblyRepresentationService` for the Owner linked to `UserId`.

Coefficient contributed = `Unit.CoefficientPercent` (not SharePercent × Unit unless future co-ownership rule is defined). Demo uses SharePercent=100.

Copropiedad: model allows multiple Ownership rows per unit; current accreditation claims each ownership unit fully — **documented limitation** if SharePercent &lt; 100 without fractional rules.
